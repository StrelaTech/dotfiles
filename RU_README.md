Dotfiles

Мои личные конфигурационные файлы для Hyprland и связанных инструментов на Arch Linux.

🚀 Возможности

· Hyprland - Оконный менеджер с динамической тайлингом
· Hyprpaper - Управление обоями
· Waybar - Статус-бар
· Wofi - Лаунчер приложений
· Kitty - Эмулятор терминала
· Fastfetch - Отображение информации о системе
· Nemo - Файловый менеджер
· Grim + Slurp - Инструмент для скриншотов
· NetworkManager - Управление сетью

🎨 Дизайн

· Минималистичная черно-белая цветовая схема
· Чистый и функциональный интерфейс
· Возможность смены обоев

⌨️ Горячие клавиши

Сочетание Действие
Super + T Открыть терминал
Super + E Открыть файловый менеджер
Super + P Сделать скриншот
Super + R Лаунчер приложений
Super + Q Закрыть окно
Super + M Выйти из Hyprland

📦 Зависимости

Установите следующие пакеты:

```bash
hyprland hyprpaper waybar wofi kitty fastfetch grim slurp wl-clipboard brightnessctl pactl nemo networkmanager network-manager-applet
```

🔧 Установка

Автоматическая установка (setup.sh)

1. Клонируйте репозиторий:

```bash
git clone https://github.com/StrelaTech/dotfiles.git
cd dotfiles
```

2. Запустите скрипт установки:

```bash
./setup.sh
```

⚠️ Предупреждение: Скрипт установки может быть нестабильным и не гарантирует работу на всех системах. Он перезапишет существующие конфигурационные файлы. Сделайте резервную копию текущих конфигов перед запуском.

Ручная установка

Если скрипт установки не работает, вы можете вручную скопировать конфигурационные файлы:

```bash
# Скопируйте каждую папку конфигурации в ~/.config/
cp -r fastfetch ~/.config/
cp -r hypr ~/.config/
cp -r kitty ~/.config/
cp -r waybar ~/.config/
cp -r wofi ~/.config/
```

💡 Примечание: Ручная установка дает вам больше контроля и рекомендуется, если вы хотите сохранить существующие конфиги или выборочно установить компоненты.

3. Чтобы сменить обои, замените файл hypr/wall.png на свое изображение (сохраните то же имя файла).

🌐 Сеть

Для управления сетью используется NetworkManager. Для графического управления используйте nm-applet.
